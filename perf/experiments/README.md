## Naming Convention

`<function>-<description>_<YYYY-MM-DD>/`

- Function: the DSP/Kernel being optimized (e.g., `dq-checkAllRdCosts`, `sad`)
- Description: brief qualifier (e.g., `minselect-debug-3`, `avx2-port`)
- Date: ISO date of experiment creation

## Skill Integration

Experiments are generated by the `asm-optimizer` skill's `archive-experiment`, `iterative-optimize`, and `bench` commands. Each experiment directory should contain:

```
README.md           — session summary, results, conclusions
src/                — ASM source, microbenchmark, build script
specs/              — pipeline specs, gap analysis, diagrams
results/            — benchmark data, perf stat output, comparison tables
```

## Per-Experiment Status

### `fix-dq-checkAllRdCosts-asm-minselect_2026-05-12/`

Full ASM implementation of `DQIntern::checkAllRdCosts` with min-select blend mask bug fixes, precomputed LEA-based cffBits addressing, and all 3 spt paths (ISCSBB, SOCSBB, EOCSBB) corrected. ASM is bit-exact but 0.93x vs C++ SIMD. Bottleneck was L1D load port throughput (P2/P3), not frontend decode. SoA transposition of `gtxFracBits` evaluated and rejected as too invasive for sub-noise gains.

### `sad-avx2-port_2026-05-12/`

SAD ASM for all 4 block sizes accepted and wired. HAD (SATD) ASM identified as next target with larger potential gains (30-50% estimate from eliminating register spills), currently WIP.
